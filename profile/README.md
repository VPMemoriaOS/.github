# VPMemoriaOS

## Public Projects

### [MemoriaOS Specification](https://github.com/VPMemoriaOS/memoria-spec)

An implementation-independent specification for MemoriaOS, a Knowledge Operating System architecture designed to transform heterogeneous information into structured, traceable, and reviewable knowledge.

### [MemoriaOS Hermes](https://github.com/VPMemoriaOS/memoriaos-hermes)

A reference implementation of the MemoriaOS specification using Hermes Agent.
