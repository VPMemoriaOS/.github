# Security policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately:

1. In the affected repository, open the **Security** tab and choose **Report a vulnerability**, if it is available.
2. Otherwise, contact the organization owners privately through GitHub.

Include what is affected, how to reproduce the issue and its potential impact. Do not include exploit code against systems you do not own.

You will get an acknowledgement after the report is reviewed. Please keep the report confidential until a fix is available.
