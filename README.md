# VPMemoriaOS

This is the public organization-level repository of VPMemoriaOS.

## Scope

- **Organization profile** — [`profile/README.md`](profile/README.md) is shown on the [VPMemoriaOS organization page](https://github.com/VPMemoriaOS) and gives an overview of publicly available projects.
- **Default community health files** — used by every organization repository, public or private, that does not have its own file of the same type:
  - [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) — issue form *Engineering change*; blank issues stay allowed. A repository with its own issue templates uses none of these.
  - [`.github/pull_request_template.md`](.github/pull_request_template.md) — pull request description.
  - [`SECURITY.md`](SECURITY.md) — how to report a vulnerability privately.

## Public by design

Everything in this repository is publicly visible. It contains only generic, public information and no details about private repositories, infrastructure or internal projects.
