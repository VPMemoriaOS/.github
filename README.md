# VPMemoriaOS

This is the public organization-level repository of VPMemoriaOS.

## Scope

- **Organization profile** — [`profile/README.md`](profile/README.md) is shown on the [VPMemoriaOS organization page](https://github.com/VPMemoriaOS) and gives an overview of publicly available projects.
- **Default community health files** — files such as issue forms, a pull request template and a security policy placed here are used by organization repositories that do not have their own.

## Public by design

Everything in this repository is publicly visible. It contains only generic, public information and no details about private repositories, infrastructure or internal projects.
